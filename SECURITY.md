# Security policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub private vulnerability reporting](https://github.com/neoromantic/ai-usage/security/advisories/new).
Don't open a public issue for them.

Include what you found, how to reproduce it and which version you used. You should get a reply
within a week. Once a fix ships, the advisory is published with credit to you, unless you'd
rather stay anonymous.

## Supported versions

Only the latest release gets security fixes.

## Secrets

Never put tokens, session files or personal data in issues, pull requests or test fixtures.
