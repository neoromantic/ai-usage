Nothing changes in ai-usage itself since v0.14.0, whose notes say what it brings: your projects reach only the teammates who work in the same repository.

This release fixes how a release reaches Homebrew and BB. Homebrew 7 loads no formula from a tap it does not trust, so the release's check of its Homebrew formula stopped, and with it the BB plugin's publication. v0.14.0's formula went into the tap by hand, and `brew upgrade neoromantic/tap/ai-usage` has installed it since. With v0.14.1 the BB plugin, `@goodit/bb-plugin-ai-usage`, reaches this release through `bb plugin update`, and Homebrew gets it as before.
