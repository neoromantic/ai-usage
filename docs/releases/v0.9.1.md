## Windows collections stay in the background

The 15-minute collection no longer opens a console window. Existing schedules switch to the background launcher automatically when the updated collector next runs.

Task Scheduler query failures, such as access denied or an unavailable scheduler, are now reported instead of being treated as a missing task. This works independently of the Windows display language. Removing a schedule also reports a failed query rather than silently succeeding.

Installation, reinstallation, Claude and Codex collection, the terminal report and interactive view, team uploads and downloads, and an automatic scheduled run after a reboot were checked on Windows 11 ARM64.

## Upgrade and collection health

Run `ai-usage update` to update now. Script installs also update at a scheduled run; Homebrew installs update with `brew upgrade neoromantic/tap/ai-usage` or `ai-usage update`.

Use `ai-usage status` to check whether collection succeeded. The Windows task runs through `conhost --headless`, so Task Scheduler reports the launcher's exit code rather than the collector's.

## For the website

The README now describes Windows collection without a console window and reports scheduler failures on localized Windows. Windows 11 ARM64 has been checked in a real VM. Install commands, report appearance, JSON, and demo pictures are unchanged.
