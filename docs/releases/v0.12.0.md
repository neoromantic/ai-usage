## AI Usage in BB

AI Usage is now a plugin for [BB](https://getbb.app). It puts your team's report on a page of its own: what needs attention, each subscription's limits with what is left and the forecast at reset, what the subscriptions cost and the questions about them, which machine used which subscription over a day, 7, 30 or 90 days, and every machine with its notes. A Team usage card in the sidebar's footer shows the top three alerts and a bar for each subscription. The plugin shows what `ai-usage report --json` says, worded as ai-usage words it, as the menu bar app does.

Until it is in BB's catalog, install it with:

```sh
bb plugin install npm:@goodit/bb-plugin-ai-usage
```

## What it installs, and where

When the plugin starts on a Mac or Linux machine where BB runs as a person, not root, and there is no ai-usage, it installs ai-usage there, once, with the install.sh of the latest release:

- the `ai-usage` binary goes into `~/.local/bin`, and the system scheduler (launchd or cron) runs it every 15 minutes, with BB open or not;
- it updates itself from GitHub Releases, as any script install does;
- it leaves your shell profile alone and does not add the menu bar app; Settings → AI Usage → Install menu bar app adds it on macOS 14 and later.

A machine that already runs ai-usage, from the installer or Homebrew, is used as it is: nothing is installed. Otherwise the page offers Install, with a field for a team key a colleague sent you, and an example team of made-up data to look at first. Settings → AI Usage also lists your other BB machines, each with an Install that joins it to the same team. Invite copies a message with your team key; Join pastes one.

## Removing it

Removing the plugin from BB leaves ai-usage collecting on every machine it installed. To take ai-usage off a machine, use Settings → AI Usage → Remove ai-usage before you remove the plugin, or run `ai-usage uninstall` there.

Good to know: BB's Cursor, OpenCode and Pi agents are not counted; anything that runs in BB as you, agents included, can read the team report through the plugin and ask it for the team key; and the plugin sends no notifications, the menu bar app does.

## Homebrew

`brew info neoromantic/tap/ai-usage` now says to run `ai-usage uninstall` and then `brew uninstall neoromantic/tap/ai-usage` to remove it, instead of `ai-usage schedule remove`, so the menu bar app and its launch agent go too.

## Upgrade

Script installs update at a scheduled run; Homebrew installs update with `brew upgrade neoromantic/tap/ai-usage` or `ai-usage update`. Nothing changes in the report or on the relay.
