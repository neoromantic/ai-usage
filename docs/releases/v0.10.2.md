## One machine that never updates no longer holds the team back

What a newer release adds to the team's snapshots, such as the answers people type with `ai-usage cost` since v0.10.0, waited until every machine ran that release. A machine nobody updated kept it off for everyone.

Now a machine that keeps reporting on an older release for 3 days after a newer one came out no longer holds it back. That machine, which cannot read the newer snapshots, sees only itself until it updates; the report keeps saying on every other machine how long it has not updated. A machine that stopped reporting, such as a laptop asleep while a release came out, still holds it back until it wakes and updates, or until `ai-usage team forget-device` forgets it.

## Upgrade

Script installs update at a scheduled run; Homebrew installs update with `brew upgrade neoromantic/tap/ai-usage` or `ai-usage update`.

## For the website

Nothing the website shows changed.
